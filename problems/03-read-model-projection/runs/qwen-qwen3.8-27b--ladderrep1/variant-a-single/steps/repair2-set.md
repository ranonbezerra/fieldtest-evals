## reply

Looking at the error list as a whole, there is exactly **one distinct mistake**: the Prisma client has not been generated, so `@prisma/client` exports none of the model types, the `Prisma` namespace, or `PrismaClient`. Every single error — the 30+ TS2305 "no exported member" errors, the TS2339 "property does not exist" errors on `PrismaService` (because it doesn't actually extend a real `PrismaClient`), and the two TS7006 implicit-`any` errors (because `$queryRaw`'s generic can't resolve without the namespace) — all trace back to this one root cause.

The fix is a single type-declaration file that declares what `@prisma/client` should export, so TypeScript can resolve all the imports regardless of whether `prisma generate` has been run.

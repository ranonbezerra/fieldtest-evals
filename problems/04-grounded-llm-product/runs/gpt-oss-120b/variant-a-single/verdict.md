## The shape is right

M1 `evaluate(question, sources, expectedFacts, falseFacts, mode)` takes the sources.
M2 is literal: `const finalScore = Math.min(faithfulnessScore, helpfulnessScore)`.
M3 splits on sentence boundaries and filters. M4 carries `falseFacts: string[]`
described as "strings that must NOT appear". The interfaces are separated cleanly —
`llm-client.interface.ts` beside a fake implementation.

M5 is partial: the service `throw`s `new Error('not covered by my sources')` where the
must-have asks that "the service says so". An exception is a refusal, but a thrown one
is not an answer.

## The redactor does not redact

    private redactHint(answer: string): string {
      return answer.replace(/\b([A-Z][a-z0-9]+)\b/g, (match, p1, offset, str) => {
        const isFirstWord = offset === 0 || str[offset - 1] === ' ';
        return isFirstWord ? match : '[redacted]';
      });
    }

`str[offset - 1] === ' '` is true for every word after the first in ordinary prose, and
`isFirstWord` returns the match unchanged. Run against a sentence of the kind this
product exists to protect:

    in:  The Gravel Wretch guards the Bakery cellar. Weaken it with Moonlight Shards.
    out: The Gravel Wretch guards the Bakery cellar. Weaken it with Moonlight Shards.

Every boss name, every location, every item survives. M6 is the requirement the
problem is built around — "the restricted mode is produced by constraining the full
answer" — and this constrains nothing. The condition was meant to spare the first word
of a sentence and instead spares all of them.

## The test suite tests itself

`test/answer.spec.ts` imports exactly two things:

    import { strict as assert } from 'node:assert';
    import { describe, it, expect } from 'vitest';

Nothing from `src/`. It then defines its own:

    // Very naive fake implementation that simply concatenates sources.

Five tests, four green, and not one of them executes the service, the evaluator, the
grounding gate or the redactor. **The suite would pass identically if `src/` were
deleted.**

The failing one is the toy disagreeing with itself: its local `answer()` returns
`Answer based on 1 source(s).`, its local `evaluate()` looks for `'4 shards'` in that
string, and scores 0 where the assertion wants 1.

`harness_ergonomics: 0`. And the fake client is not scriptable per scenario — it
returns `${prompt} (generated by FakeLLMClient)`, echoing its input, so no scenario can
plant a confident lie for the judge to catch.

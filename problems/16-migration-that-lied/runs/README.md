Two notes for this problem:

**It needs Docker.** Start it for this problem and shut it down afterwards — its VM
holds 5–6 GiB resident while idle, which is the difference between headroom and swap
on this machine. See [`harness/host-limits.md`](../../harness/host-limits.md).

**Run the deliverable's checks yourself, against the untouched fixture.** A check that
passes there is a check that proves nothing, and that is the whole subject of this
problem.
